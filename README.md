Healthy Life Expectancy vs Life Expectancy Analysis

Project Overview
This repository is part of an ongoing series exploring healthcare data through SQL.
The goal is to analyze Life Expectancy (LE) and Healthy Life Expectancy (HALE) trends, starting with the United States and expanding globally over time. With the layering in of GDP data as well expected

Current Focus
United States (2019)
Comparing Life Expectancy at Birth vs Healthy Life Expectancy at Birth
Calculating the gap in years lived in poor health
Future Development
Trend analysis (2000–2021)
Gender differences over time
Age 60 comparisons
Global comparisons
Visualizations and dashboards
📂 Repository Structure
/queries → SQL scripts for each analysis
/data → Sample datasets (if shareable)
/visuals → Charts and graphics for LinkedIn posts
